# terminals and layouts

a session's terminal has tabs along the top, and a screen can hold several terminals at once.

1. press + after the last tab to add another agent, a terminal, a blueprint or the browser as a tab. you can also drag a session from the drawer onto a tab strip.
2. the components menu (grid icon in the drawer bar) arranges panes in columns, rows or a grid and saves the arrangement. drag tabs between panes. on a phone the panes become a swipeable strip.
3. a saved arrangement shows up in the drawer's layouts section; click it to reopen the whole grid. an open layout has a command bar that searches every terminal at once, or sends one command to each terminal whose ">" toggle is on.
4. search inside a terminal with the magnifier on its bar, or ctrl+f (cmd+f on a mac). the terminal reconnects and repaints by itself after your device sleeps or the network drops.
5. when several windows show one session, the crown in the terminal toolbar picks the window that sets the pane size; the others scale to fit.
