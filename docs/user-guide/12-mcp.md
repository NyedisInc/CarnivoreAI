# the mcp server

carnivore runs an mcp server on this computer so an agent, or an outside client you trust, can read sessions and act on them.

1. settings, sessions & agents, agents tab, mcp server turns it on, shows the endpoint, and mints the tokens outside clients use.
2. a read token is not low privilege: it can read redacted screens, transcripts and notes of every session on this computer and each paired computer.
3. every write from a write token waits for your approval.

## the tools

this list is read from the server when you open this page, so it is always the tools your install really has. a tool marked write changes something.
