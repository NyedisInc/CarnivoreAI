1. start a session: press + at the top of the left drawer (or cmd+n), pick an agent, then pick or type the project folder. the session opens in the terminal and appears in the drawer.
2. start a project: press + at the top of the left drawer and pick project. begin with an empty folder or open an existing one; the full path is shown before anything is created.
3. come back to work: the projects page lists every project and every session it ever had, and the sessions page lists the running and sleeping ones. a session that ended reopens from recently closed on the home screen, and after a reboot a reopen offer lists what was running.
4. the home screen is where the carnivore logo takes you: running sessions, recent ones, projects, providers and charts. use edit layout there to hide or rearrange cards.
5. a link like /session/name opens that session directly, so you can bookmark one.
