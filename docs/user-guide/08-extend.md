# skills, plugins, widgets and themes

add abilities and change how the app looks. each one has a page in the menu tab.

1. skills: browse the catalog, install a skill for everything or for one project, and use the installed tab to switch each on or off (the skills page has installed and census tabs; the catalog is warez). session skills, in a terminal's menu, shows what that one session has.
2. plugins: search the list and use a plugin's switch to turn it on or off.
3. widgets: every widget this build carries, with a switch and its own settings.
4. blueprints: save a team of sessions (agent, folder, first prompt) and launch the whole team at once.
5. themes: preview one, make it the page theme, or star it. the palette icon in a terminal bar pins a theme to that session or its project. a theme's own animation script runs only after you approve it once.
