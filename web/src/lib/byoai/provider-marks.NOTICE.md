## Notification destination kinds

The marks of slack, discord, microsoft teams, telegram, ntfy, twilio, pagerduty and amazon web services (sms via aws
sns) are path data from **simple-icons** (https://github.com/simple-icons/simple-icons, CC0 1.0, versions 11.14.0 and
the current release for ntfy). Their owners' trademarks apply, and they appear only to name the service a destination
sends to. The envelope is drawn for this app. pushover and generic webhook use the app's own bell and link glyphs.
