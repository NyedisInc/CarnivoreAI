save plugin: the restore points tab

The save plugin's RESTORE POINTS tab (web/src/cplugs/save/SessionTab.svelte) loads its own points: the two ways back explained in .rpt-ways, then RestorePoints.svelte, a table in a dashed cyan frame (.rpt-frame) with a pin toggle and the dashed cyan .rpt-action button "resume exact"; the line above it tells the outcome, and a refused session start for a missing permission shows the server's sentence as it is.
