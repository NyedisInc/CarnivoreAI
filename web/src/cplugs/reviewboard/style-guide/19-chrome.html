The board has NO sidebar (issue #1760, docs/reviewboard.md, "Payload pages"): its controls live in the title strip (.rb-strip, which wraps onto a second row on a narrow board) and the page frame takes the full width under it. Styled in web/src/cplugs/reviewboard/header.css. They are OUTSIDE the sandboxed frame, so the page can only supply its state and never press a key. ThemePicker.svelte is the shared .oc-field select (.rb-theme): it repaints only the page frame in another theme. For a revision that declares payload_mode, PayloadControls.svelte (.rb-controls) adds the save disk (the notepad widget's own EditorControls disk: --oc-yellow while the state is unsaved or saving, --oc-green once saved, --oc-coral with a short word when the write was refused; pressing it saves now), the save stepper (.rb-saves: older and newer .rb-icon keys around .rb-position, the .rb-label reading save 3 of 5 or draft), a note key (an .rb-icon, accent while a note waits) opening the notes panel below, and Send (.rb-send on the Task Manager's own send key, .oc-btn.oc-btn--sm: .oc-btn--confirm once there is a state to send, .oc-btn--ghost before). PayloadNotices.svelte (.rb-notices) is the one quiet row under the strip: the confirm line after a send (.rb-confirm, .rb-warn) and the note of the save on show. Tokens only; focus is the shared rule; 40px keys on a touch screen.
