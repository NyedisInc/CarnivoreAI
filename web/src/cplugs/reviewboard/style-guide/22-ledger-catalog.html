review board plugin: closed reviews on the projects page

The review board's CLOSED REVIEWS group (web/src/cplugs/reviewboard/ClosedReviews.svelte) is the first: boards whose task is done, newest closed first, each a closed session row's twin on the same .ph-scols grid (.rb-closed-row: the closed square mark as StateMark.svelte draws it, the board title, the task title in the wrapper column, the revision count as a .ph-tag, the last revision's age, and a confirming "open" that, like a tap on the row, opens the board as a page row), cut to the page's preview with "show all" (.rb-closed-more), one quiet .ph-empty line when the project has none, and a failed read said on the same line in .ph-gone.
