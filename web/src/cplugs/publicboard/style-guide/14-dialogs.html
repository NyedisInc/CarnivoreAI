public review links plugin: the share window

share a review board publicly
web/src/cplugs/publicboard/ShareLinkModal.svelte renders ModalShell in the text-prompt-modal look and is opened by the board header's share key (web/src/cplugs/publicboard/ShareLinkKey.svelte, an IconButton with the globe icon, contributed through web/src/cplugs/sdk/board-header-keys.ts so it exists only while the plugin is on). Two base RadioGroups pick how long the link lasts and which revision it shows, the base Button in the confirm variant makes it, and the whole link then shows ONCE in a base Field (.pbs-once) with a copy key and a warning line (.pbs-warn). Below, the board's links are a base List of rows: id, mode, end, a state Tag, and a danger IconButton to remove a live one; .pbs-label captions the list, .pbs-explain and .pbs-none are the quiet lines, a quiet danger Button "remove all" under the list opens the shared ConfirmPopup, .pbs-remove keeps that key one row high, .pbs-actions lays the buttons out and .pbs-error prints a refusal in the destructive color. See docs/publicboard.md.
