# Third-party notices

Carnivore bundles and depends on open source software under its own licenses.

- Vendored client libraries live under `client/vendor/` and `client/js/vendor/`, each with its license header intact.
- Notices and license texts for the software packaged into the desktop app are in `macOS/payload/notices/`.
- Python dependencies are pinned in `requirements.lock` and JavaScript dependencies in `web/package-lock.json`; each package carries its own license.
