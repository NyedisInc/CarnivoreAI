brand: name, logos and background art

The visible brand is Carnivore. It is raster art in fixed files, drawn at fixed heights, and only one brand mark is on screen at a time. Every identifier underneath stays Cloude.

source
All are cut from macOS/assets/AppIcon-1024.png by scripts/generate-web-icons.sh. Change the master and regenerate; never edit a size by hand.

theme background art

what
Every bundled theme ships background.webp (1254x1254) and preview.webp (240x240) in its own folder: the claw and wordmark redrawn in that theme's palette (docs/theme-catalog-layout.md). Above: carnivore's background, then five previews.
how it paints
Only behind the terminal, declared in the theme's theme.json background block, under a scrim of the terminal's own colour (carnivore dim 0.8, default 0.9). A session can swap, borrow or switch off its picture (docs/terminal-background.md). Previews appear on the themes page and the theme pickers.

the name

formuse it for
CARNIVOREthe wordmark art only. Never type the capitals; a title row that shows it in capitals does so by CSS.
carnivoreUI copy, lowercase like every other string, from the catalog: "carnivore skills catalog", "carnivore moves new sessions".
Carnivoreproper-name places outside the copy: the document title ("music-service - Carnivore", setPageTitle in client/js/app.js), the manifest name, the macOS app name, an aria-label ("Carnivore, go to the home screen").
carnivore.aithe public site (its own private repo, carnivore-site); catalog.carnivore.ai is the skills catalog and its admin. Lowercase, and only where the UI links out.
Cloudeevery identifier: the tmux socket cloude, the cloude_* session prefix, cloude.db, CLOUDE_* variables, the bundle id com.cloudecode.menubar. Deliberate; never "correct" it (docs/rename-carnivore.md lists what the rename still recognises).

do not

  • Two brands on screen. The header drops its mark while the drawer, which carries the wordmark, is open.
  • A redrawn or recoloured mark. The art is raster, full colour; hover and open states change opacity, never colour. No SVG copy, no CSS filter, no theme tint.
  • A stretched mark. Set the height and let the width follow; always ship the @2x in srcset.
  • The claw as an action or status icon. It means Carnivore, nothing else; actions use the icon set.
  • Background art in chrome. It paints behind the terminal only, through the theme manifest, never as an <img> on a page.
  • Carnivore in an identifier. A new socket, prefix, key or variable follows the rename register, not the brand.
