page shells, headers, drawers and sidebars

The frame every screen sits in. client/index.html is ONE document: the screens are divs, one visible at a time (.screen.active), under one sticky header, with the agents drawer on the left and one shared right-hand slot for the file or notes drawer. Overlays (the ledger, the catalog, the themes page, a new page) paint over the active screen below the header and restore nothing when they close.

Task Manager post formatting
Every Task Manager text surface draws a safe markdown subset through ONE renderer (web/src/cplugs/huddle/TaskManagerMarkdown.svelte, parser task-manager-markdown.ts); another plugin draws the same words through the sdk seam (web/src/cplugs/sdk/Markdown.svelte, registered by the Task Manager at start, plain text when the Task Manager is off), as the review board does for a revision summary: the row's title, latest line, description and posts, the thread, the review block and the answer popup (item name, context, prompts, help, options, reasons), whoever wrote the words. A one-line host passes inline: the text draws as one run in .hmd-line (an inline span), so the host's own ellipsis or line clamp cuts the DRAWN words and bold, italic and code keep their styling up to the cut. A folded post passes limit and more: the parsed tree is cut (task-manager-markdown-clip.ts), never the source text, so no marker ever shows at a cut. Native tooltips and aria-labels take mdPlain, the words with every marker gone. It builds nodes, never HTML: a tag in a post shows as literal text, links are http and https only and open in a new tab. Syntax: paragraphs, **bold**, *italic*, inline code, fenced code, bullet and numbered lists (one nested level), ***bold italic***, bold and italic across the lines of one paragraph, # and ## headings (small tracked capitals, .hmd-h), links, GFM pipe tables and a ```kv fence of key: value lines. A table (.hmd-table) scrolls sideways in its own box (.hmd-scroll), hairline rows from --oc-line-faint, mono tracked column heads, and a column of all numbers is right aligned with tabular figures (.hmd-cell--right). A key: value block (.hmd-kv) is an aligned grid, labels in --oc-text-secondary mono. Code reads on --oc-ground-hover; links in --oc-cyan. Anything unrecognized, and a malformed table, stays plain text.

INSET: a host calls provideInset() (web/src/opscenter/ui/page-inset.ts) and every Page below it draws no title bar; its sub and actions ride at the right end of the bar row (.oc-page__inset-end).

page layers: the band and the data

the rule
how
Use Page.svelte and its slots and the layers come free. A page-specific row that belongs to the top band paints --oc-ground-band; a region of data never does. Never --oc-ground-panel for a band: it is the theme's --color-bg, which on some themes is lighter than the chrome and on others equals the page, so the band either goes off-theme or disappears.
