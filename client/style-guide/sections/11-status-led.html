the status light

The app's most important visual vocabulary. Every place a session appears carries a small two-part light: the inner dot says what the conversation is doing, the outer ring says whether something is running and whether anything waits for you. It is ONE component in two trees, proven byte identical by StatusLed.parity.test.ts. Full model: docs/session-status.md.

The eight state NAMES stay eight; only the paint collapses onto five hues. Every state paints the same lit diameter, so one busy session in a column of quiet ones never looks bigger than its neighbours. unknown is a real answer and is never drawn as idle.

use
Every surface that shows a session: a drawer row, a home table row, a tab, a menu entry, a group header (collapsed groups only, #525). Svelte: <SessionFace row={row} /> (web/src/lib/sessions/SessionFace.svelte), the one piece that draws a session's face and hands StatusLed every signal on the row at once (unread, startup_gate, status_source, transport, the hint, the parked summary, the usage limit, the paired Mac); no other component renders StatusLed for a session. Legacy: client/js/status-led.js with the same signals. Beside a provider mark, use SessionFace with mark (icons).
pass signals
The light is TWO independent rings, so a surface passes SIGNALS, not just the status word: unread, startupGate, statusSource, activityHint, transport and usageLimit (usageLimitLabel(row) in led.ts). A surface that drops one silently loses a state (the unread ring, the red of a dropped socket). All of them live on the SessionInfo WRAPPER, not on info.session.
props
size takes a CSS length ('10px') and sets --led-size; showLabel prints the words next to the light, as this specimen does.

access
Every light has an accessible label and, being an icon, a tooltip in words, including where the status came from (via registry, via transcript). Reduced motion stops the breathing ring at full brightness.

common mistakes

  • Changing one tree. Edit led.ts and status-led.js together or half the app's lights change; the parity test fails on purpose.
  • "Fixing" a grey flash in the client. The watcher goes unknown only after three missed cycles; a grey flash under load is the server being honest (#524).
  • A copied light. A dot painted with a status colour next to a name is a second, drifting implementation. Mount the component.
  • An aggregate light on an expanded group. The group header shows the light only while collapsed (#525).
