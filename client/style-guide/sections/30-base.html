base: one scale, one component set, every theme

The design base is one geometry and one component set that every theme extends with color only (issue #2033, phase 2 of #1103). This first slice is additive: the tokens below exist in web/src/opscenter/tokens.css, no app screen reads them yet, and nothing in the app moved. Every value is the one the app already uses most, so moving a screen onto the base is a rename. Pick a theme at the top to repaint this section; the last specimen shows every shipped theme side by side.

every shipped theme

a theme sets color
A theme owns its grounds, ink, accent, status hues, font family and (clamped) corners. The base owns spacing, type sizes, heights, borders, depth, motion and stacking. Every surface above is derived from the theme's page ground and ink, so a theme that sets two colors still gets five distinct surfaces.
decisions taken without a ruling yet
Alex has not ruled on #2033, so this slice follows the plan's recommendations: the 2px and 6px steps (decision 2), a 2px control corner and 4px panel corner as defaults (3, not yet applied to any control), the control line at 3:1 (6), clamped theme corners (7) and a 32px default control (10).
