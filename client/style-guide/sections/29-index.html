class and component index

Every stylesheet and Svelte component Carnivore ships, with every CSS class it defines, filed under the section that documents it. This list is rendered from client/style-guide/registry.json, and tests/test_style_guide_drift.py fails when the shipped code and the registry disagree in either direction, so nothing here is stale and nothing shipped is missing.

To see the gap after a change: venv/bin/python3 -m tests.helpers.style_guide_inventory. Add each new class under the file that defines it, in the section that documents it, and describe it in that section's fragment.
