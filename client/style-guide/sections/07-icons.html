icons and marks

Every icon is inline SVG compiled or scripted into the page: nothing is fetched, so no img-src relaxation and no icon can fail to arrive. Every stroke is currentColor, so the surrounding text colour, and therefore the theme, colours it.

the shared 16px glyphs

liveweb/src/lib/Glyph.svelteevery record in client/js/icons/glyphs.js

These glyphs are DATA, not markup: one set of coordinates in client/js/icons/glyphs.js, drawn by two renderers (glyphSvg(name, size) for the legacy tree's innerHTML, <Glyph name="..." /> for Svelte). Add a glyph by adding its records there, never by pasting an SVG string into a component. They are 16x16 on a 0 0 16 16 box, currentColor. A glyph may reuse another set's geometry through a transform attribute on its records (wolf, the Pack icon, is the opscenter 24 box outline scaled by 0.6667; both renderers pass transform through, so ONE outline draws the Pack everywhere). The row menu's own icons (client/js/session-row-menu-icons.js) borrow from this table for the same reason.

the icon picker and picked icons

liveweb/src/lib/icon-picker/IconPicker.svelteinside a green parent, a heading drawn by IconMark above it
liveweb/src/lib/icon-picker/IconPicker.sveltethe same picker in a violet parent, nothing chosen
use
The ONE way a user picks an icon for something they named: a group, a wrapper group, a widget, a user tab (issue #764). <IconPicker value={icon} onChange={(id) => save(id)} />, with optional onCancel (Escape) and autofocus. It never saves: the caller writes the id through its own documented route. Never build a second picker. Contract: docs/icon-picker.md.
render
Show a picked icon with <IconMark id={icon} size={12} /> in Svelte, or CloudeGlyphs.iconSvg(id, 12) in the legacy tree. Never map an id to a Glyph name by hand. An empty or unknown id draws nothing at all, so a row with no icon lays out exactly as it did before.
stored value
The icon's id string from client/js/icons/icon-registry.js, or null for none, inside the one JSON shape (#727). Ids are forever: never rename or remove one; retire it through RETIRED_ICON_IDS.
colour
keyboard
The grid is one tab stop (listbox): arrows move a cell or a row of eight, Home and End jump, Enter or Space chooses, Escape calls onCancel. ArrowDown in the search field enters the grid. "No icon" is always the first cell.
adding an icon
Draw it in client/js/icons/glyphs.js on the 16 box, then add one entry to icon-registry.js and its icon.* name to the catalog. Action glyphs (trash, close, pencil, restart) are never pickable: a group wearing a trash can reads as an instruction.

a wrapper's mark

use
Every surface that shows a launch wrapper draws it through the ONE mapping, client/js/wrapper-mark.js (issue #1004): WrapperMark.svg({icon, family}, 14) in the legacy tree, wrapperMark(icon, family) (web/src/lib/sessions/agent-marks.ts) in Svelte. The wrapper's picked icon when it names one this build can draw, else its family's provider mark. Surfaces today: the wrappers page's cards and detail pane, the new session menu, the restart and wake picker.
class
.wrapper-mark (client/css/wrapper-mark.css) sizes the mark in a picker row: a 16px box, no colour of its own. data-mark-source is icon or family.
stored value
agents.wrappers[].icon in config.json, written by PUT /api/v1/wrappers/{id}/icon from the icon picker on the wrappers page's detail pane; exported in the share document (version 2).
mistakes already made
Mapping an icon id to a glyph by hand, or falling back to nothing: an unknown id falls back to the family mark, which is what the wrapper wore before an icon was chosen.

common mistakes

  • A second robot, a second kebab, a hand-drawn provider mark. Each exists once; a copy drifts and the same thing is drawn two shapes on two screens.
  • Misaligned tab icons. Mixing 14 and 16 and 20 in one row, or a mark with its own margin, puts the row out of line (#514, #569). Every icon in a tab passes size={14} and centres in a fixed box.
  • Icon-only meaning. A glyph with no label and no aria-label means nothing to a screen reader and little to a new user.
  • An <img src> icon. It is a network request, it cannot take currentColor, and it does not follow the theme.
