foundations: base elements

The house look on plain html, the way a reset like Bootstrap's Reboot gives a page its defaults (issue #2033, slice 2b). It lives in web/src/lib/base/elements.css, in the base cascade layer that client/css/layers.css declares first, so a component, a page, a utility or any legacy rule still wins property by property. A screen writes plain markup and inherits; a component sets only what differs.

a region
data-oc-base on any element gives every element inside it with no class the base look: buttons, text fields, select, textarea, links, h1 to h6, label, small, code, kbd, hr, fieldset and legend, and a classless table. A card (Card.svelte) is a region.
one element
data-btn (secondary, confirm, danger, quiet, row) with data-size="sm", and data-field, give one element the look anywhere, class or no class. Button.svelte and Field.svelte write them; legacy client/js writes the same attributes.
a control that draws its own box
A tab, a tool control, a name that is the control or a corner mark keeps the base's colors, focus and states and sizes itself: data-size="auto" takes the height floor away, data-size="bare" also uses the font's natural line height, and data-overflow="visible" lets a badge or dot hang outside it (the base clips an unwrapped label). data-focus="ink" makes the focus edge follow the control's own text color, for a control with no outline whose only visible edge is the focus one (a chart mark, a legend item, a glance tile): reserve a 1px transparent border for it to color. buttonAttrs(variant, 'auto' | 'bare') writes the size. A component never cancels the base by setting its private --_btn-* variables.
the shells' own spacing
The manager frame, the widget head, the top bar, the tab strips and the table read a step of --oc-space-* first. A value with a job of its own and no step is a token named for that job in tokens.css (--oc-gap-parts, --oc-gap-hair, --oc-pad-snug, --oc-gap-mark, --oc-card-pad-y, --oc-cell-pad-x, --oc-tab-end-pad, --oc-topbar-pad-left, --oc-topbar-word-gap, --oc-topbar-chip-gap, --oc-head-chevron-room, --oc-fs-tab-numeral). --oc-mask-solid is the opaque black a scroll-fade mask uses (a mask reads only alpha, so it never takes the element's text color). The --oc-pp-space-* scale is the publish page's alone, and a test holds it there.
why not the whole app yet
Measured: some screens style a classless element only through its container (the sessions page view switch, the Task Manager yes or no, the markdown preview headings). The base would fill the properties those rules leave to the browser and move them. A screen joins by putting data-oc-base on its root when it is migrated, with its own before and after.
sizes
Buttons and fields are --oc-control-h tall, a small button --oc-control-h-sm, a row trigger --oc-row-h (--oc-tap on a phone). Corners are --oc-radius-control; every boundary is a reserved 1px border the one focus rule brightens.
