typography

One family, one small scale. Carnivore is set entirely in the platform monospace (--font-mono: ui-monospace, SF Mono, Menlo, and so on down the theme's list). Hierarchy comes from size, case, tracking and the text tier token, never from a second typeface or a heavy weight.

tracking: --oc-tracking-title (every widget header's name, one value) --oc-tracking-label --oc-tracking-wordmark; family: --oc-font resolves to --font-mono. A component never sets type inline.

labels
Small tracked capitals: font-size: var(--oc-fs-micro) (field labels) or var(--oc-fs-title) (title rows), letter-spacing: var(--oc-tracking-label) or var(--oc-tracking-title), text-transform: uppercase. Copy .pl-label and .pl-title (title rows). Uppercase is for these compact labels only, never for a sentence.
body
12 to 13px, --oc-text-primary, line height about 1.45 to 1.6. Supporting text steps down one tier (--oc-text-secondary), not one size.
buttons
12 to 13px mono, lowercase labels (the restart picker footer). See buttons.
numbers
Figures use the same mono face, so columns of numbers align without tabular-nums. Compact counts read 447k/1M (compactContextTokens); reset times round to the nearest minute (resetParts in client/js/labels/usage-panel.js), never "12:59".
truncation
The primary label truncates first (min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap); secondary info sits to its right, dimmed, middle-dot separated, and never wraps (acme claude · max, PR #548). Label length must never silently widen a slot.
copy
Lowercase and plain. No em dashes, no en dashes, no emoji, anywhere, including the catalog. Every string from client/js/i18n/catalog.en.js.
themes
Type tokens do not change per theme. A theme may change --font-mono; nothing may assume a glyph width beyond "monospace".

common mistakes

  • A second typeface. Gold master paired a sans for prose; shipped Carnivore did not. One family.
  • font-family: var(--oc-font) or a named face. Write var(--font-mono); naming a face changes advance widths, which is geometry, and the terminal grid is measured.
  • Bold for hierarchy. A heavy title reads as a web page, not a terminal. Use the accent label or the bright tier; keep weights at 400 and 600.
  • Hardcoded copy. A string typed into markup cannot be translated and escapes the voice rules. Add a key to the catalog.
