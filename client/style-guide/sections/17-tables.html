tables, lists and sorting

Dense rows beat tall cards when the user compares things: sessions, projects, accounts, events. Rows are 26px on desktop, split by grey hairlines, with the identity column taking the slack and every other column pinned.

the data table

liveweb/src/opscenter/ui/DataTable.sveltefocus a row and press enter
use
Any columnar list in a compiled cell or page. Props: columns (ColumnSpec[]: key, headKey a catalog key, minPx, weight, optional align, tone, insetPx, headInsetPx, line), rows, rowKey, a cell snippet that draws one cell, and optionally onActivate, canActivate, rowLabel, rowIdAttr, rowHeight, headHeight, showHead, compact.
layout
Column heads are catalog keys drawn as tracked capitals. Hairlines are one-sided inset shadows, so a row never gains a pixel. The table grows with its cell; it never adds a second scrollbar inside the cell's own. compact draws the phone's two-line record (identity on line one, supporting facts on line two).
access
An activatable row is focusable, Enter or Space runs onActivate, and rowLabel gives it an accessible name that says what activating does.
themes
--oc-line-column, --oc-line-faint, --oc-text-primary and --oc-text-secondary, --oc-ground-hover on hover.
run chart
web/src/opscenter/ui/RunChartTable.svelte is this table at the run chart's 26px rhythm, keyed on each row's id and capped by limit: the pipeline, scheduled runs and sent list cells all draw it.

sorting

liveweb/src/opscenter/ui/SortControl.svelteopens the real CascadeMenu with radio items

One quiet button in the title row that names the current order (opscenter.session.sort.button) and opens a radio menu. Props: buttonText, menuLabel, menu (MenuNode[] with checked). A legacy list uses a native select instead (forms).

lists

  • Session rows in the agents drawer (client/css/session-sidebar-rows.css): light, mark, name, secondary info to the right dimmed and middle-dot separated, a right-justified kebab. See drawers.
  • Home lists: running, recent and projects (home).

common mistakes

  • Accent dividers between rows. Grey, --oc-line-faint.
  • A literal column head. headKey is a catalog key.
  • Stretching at 2560px. Cap the content and centre it.
