Symbols Nerd Font Mono, Regular (Nerd Fonts v3.4.0, "Symbols Only" release,
https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/NerdFontsSymbolsOnly.zip).

The file here is SymbolsNerdFontMono-Regular.ttf from that archive
(sha256 f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60)
re-wrapped as WOFF2 with fontTools, glyphs unchanged
(sha256 46c365afb00af49cc42b74fd27cf0c8d5476a62f6572ba8b12432be8aa225970).
Carnivore uses it as the last fallback in the terminal font stack so prompt
themes (starship, powerlevel10k) draw their icons; it covers only the icon
code points (Private Use Area plus a few symbols) through unicode-range.
